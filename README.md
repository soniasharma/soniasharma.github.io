# Personal blog

Astro + GitHub Pages. Posts are markdown in `src/content/blog/`.

```bash
npm install
npm run dev                      # local preview at localhost:4321
npm run new -- "Post Title"      # scaffold a new post
npm run crosspost -- post-slug   # generate Medium/Substack/LinkedIn versions
git push                         # deploys automatically
```

First-time setup: see [SETUP.md](./SETUP.md).
